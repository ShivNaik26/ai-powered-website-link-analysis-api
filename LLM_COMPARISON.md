
# LLM Provider Comparison

## 1. Overview

This project uses an LLM to analyze website content and generate structured business and SEO insights.

Three providers were reviewed:

- Google Gemini – Gemini 3.5 Flash-Lite
- OpenAI – GPT-5.4 mini
- Anthropic – Claude Haiku 5.5

## 2. Model Comparison

Prices below are published standard API rates in USD per 1 million tokens. Free-tier access, rate limits and eligibility may vary.

| Feature | Gemini 3.5 Flash-Lite | GPT-5.4 mini | Claude Haiku 5.5 |
|---|---|---|---|
| Provider | Google | OpenAI | Anthropic |
| Input price | $0.30 | $0.75 | $0.10 |
| Output price | $2.50 | $4.50 | $0.50 |
| Context window | Not verified | 400K tokens | 1M tokens |
| Structured JSON | Supported | Supported | Supported |
| Speed | Optimized for high-volume tasks | Designed for faster workloads | Listed as fastest in its model comparison |
| Main use | Data processing | Coding and general workloads | Extraction and classification |

Note: Claude Haiku 5.5 has higher input pricing for prompts exceeding 100K tokens. Its listed $0.10 input rate applies up to 100K tokens.

## 3. Response Speed and Accuracy

No direct performance benchmark was conducted for this project.

Response speed and accuracy depend on:
- Website content size
- Prompt complexity
- Model availability
- API response conditions
- Output token count

A fair comparison would require testing all three models with the same websites and prompts.

Therefore, no measured speed or accuracy ranking is claimed.

## 4. JSON Output Support

Structured JSON is important because the application returns predictable API responses.

- Gemini supports JSON output using its structured output configuration.
- OpenAI supports Structured Outputs.
- Anthropic supports JSON outputs using JSON Schema.

The application also validates the returned data using Python and Pydantic.

## 5. Cost Optimization

The following methods can help reduce API usage:

1. Limit website content before sending it to the model.
2. Avoid sending unnecessary HTML and scripts.
3. Use a cost-efficient model for routine analysis.
4. Limit maximum output tokens.
5. Reuse website extraction results when appropriate.
6. Handle API errors and rate limits gracefully.

## 6. Selected Provider

**Selected provider: Google Gemini**

Model: `gemini-3.5-flash-lite`

Reasons:
- Already integrated into the application.
- Successfully tested with website content.
- Supports structured JSON output.
- Designed for cost-efficient, high-volume tasks.
- Provides token usage information in the API response.

## 7. Limitations

- No direct three-provider benchmark was performed.
- Competitor suggestions generated by AI are not independently verified.
- Search volumes and rankings are not measured.
- API pricing and model availability can change.
- AI-generated results should be reviewed before business decisions.
